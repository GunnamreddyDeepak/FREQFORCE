# KISANQUEUE V2 — Data Dictionary

## 1. Purpose

This document defines the meaning, units, ownership, and usage of important KISANQUEUE data fields.

The data dictionary exists to prevent different services or team members from interpreting the same field differently.

---

# 2. General Conventions
